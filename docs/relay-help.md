# 中继服务使用帮助（Help: Relay Service）

> 设置面板里「中继服务器地址」旁边的 **?** 按钮会打开本文。首次安装不知道这项是做什么的？往下看 1 分钟就懂。

## 一句话解释

中继服务让你**人在外面，也能安全地连回家里/公司电脑上的终端**。你的 Ternimal 保持与中继服务器的一条加密连接；手机/其他电脑浏览器打开中继页面，凭子码即可接入你的终端——不需要公网 IP、不做端口映射、中继服务器**看不到你的任何内容**（端到端加密）。

```
[你的电脑 Ternimal] ⇄ (加密隧道) ⇄ [中继服务器] ⇄ (加密隧道) ⇄ [手机/外部浏览器]
        └──────────────── 端到端加密 E2EE，服务器仅转发密文 ────────────────┘
```

## 两种使用方式：自建 或 购买

| | 自建（免费，需一台服务器） | 购买服务（省心，开箱即用） |
|---|---|---|
| 适合 | 有 VPS / 家庭服务器，动手能力强 | 只想立刻能用，不想运维 |
| 成本 | 服务器费用 | 按套餐付费（微信小程序购买） |
| 见 | 下文【方式 A】 | 下文【方式 B】 |

### 方式 A：自建中继（5 分钟）

1. 准备一台有公网 IP 的 Linux 服务器（1 核 512M 足够），安装 Node.js ≥ 18。
2. 上传本项目 `relay/` 目录，复制 `relay-config.json.example` 为 `relay-config.json`，填入你自定义的主码（`masters` 数组）。
3. 启动：`node relay/cli.mjs serve --config relay-config.json`（生产建议 systemd + Caddy/Nginx TLS 反代，参考 `relay/README`）。
4. Ternimal 设置面板填：
   - **中继服务器地址** = `https://你的域名或IP`
   - **主码** = 你在配置里写的主码（`trelay_v1_` 开头）
   - 自签证书时填 **CA 证书路径**；用了正规域名证书（Let's Encrypt）则留空
5. 点「保存」→ 状态变「已连接」即成功。

### 方式 B：购买中继服务（微信小程序）

1. 打开微信，搜索小程序 **【小程序名称待补充】**（或扫二维码）。
2. 选择套餐并完成支付，系统会发给你一条**主码**（`trelay_v1_` 开头）和服务地址。
3. Ternimal 设置面板填入：**中继服务器地址** = 购买页提供的服务地址；**主码** = 你收到的主码；其余保持默认。
4. 点「保存」→ 状态变「已连接」即成功。到期前可在小程序内续费。

> ⚠️ 注意：一个主码同时只能在一台电脑上在线（后连的会把先连的踢下线）。多台电脑请分别购买/生成不同主码。

## 每个选项的含义

| 选项 | 含义 |
|------|------|
| 启用中继 | 总开关。关闭后本机不再连接中继服务器 |
| **中继服务器地址** | 中继服务的 URL（`https://…`）。自建=你的服务器地址；购买=购买页提供 |
| 主码 | 你的身份凭证+计费账号，**等同于密码，勿泄露**。签发子码、管理通道都靠它 |
| 显示主码 | 勾选后主码明文显示，方便核对抄写 |
| CA 证书路径 | 仅自建+自签 HTTPS 时需要填（把中继的 CA 证书存到本机并填路径）。正规证书/购买服务一律留空 |
| 局域网直连 | 同一局域网内优先直连、不走中继（更快）。默认关 |
| 退出时清除主码 | 公用电脑勾选：程序退出后抹掉主码，下次需重输。自己的电脑建议不勾 |
| 端到端加密（E2EE） | 强烈建议保持开启：密钥只存在于你的两端设备，中继服务器只见密文 |
| 状态 | 未运行 / 连接中 / 重连中 / 已连接。已连接=外部可访问 |
| 子码管理 | 给手机/他人用的临时钥匙：可设定有效期、续期、随时吊销。子码泄露只需吊销该子码，主码不受影响 |

## 常见问题

**Q：状态一直是「重连中」？**
检查：地址是否拼错、主码是否复制完整、自建的话服务器是否在线、CA 路径（自签时）是否填了。两台电脑填了同一个主码也会互踢。

**Q：安全性如何？**
中继采用零知识设计 + 端到端加密（默认开启）：服务器只见密文，无法解密你的终端内容；主码/子码均为高熵随机串。

**Q：子码默认有效期？**
6 小时，可随时在面板里续期（+1 天 / +7 天 / 长期）或吊销。
