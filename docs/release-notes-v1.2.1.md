## 中继稳定性（两起生产事故闭环）

- **「中继连接中断，正在自动重连…」死循环根除**：陈旧令牌页烧锁（4002）曾被当瞬态无限重连并持续给宿主锁定窗续期；现错误帧 4002/4005 → 终态 denied 卡片，且重试计数只在认证成功时清零（多层：错误帧门 + denied 短路 + 关闭码语义透传 4001/4002/4005）
- **认证窗口自爆修复**：业务帧在 join→auth-ok 期间发送会被宿主杀连接；现统一入 outbox 认证后冲洗（join/auth-response 控制帧豁免）

## 全面安全审计（48 项：P0×6 / P1×12 / P2×17 / P3×13）

- **P0**：中继坏帧崩溃面（ws error 兜底）、认证前窗口会话元数据泄露（零知识修复）、XFF 首值伪造（改末值）、URL 片段令牌驻留（即清 + sessionStorage 刷新恢复）
- **P1**：管理 API 自锁、限流记录无限增殖、preload 裸 IPC 桥删除、远程 create shell/cwd 白名单、口令解压封顶（zip 炸弹）、force 申请限流、退出清理保证
- **P2**：子码哈希索引 O(1)、config 损坏拒启、异步 scrypt、resize 上界钳制、证书过期自愈、托盘/日志令牌脱敏、CSP 收紧 + 反点击劫持、E2EE 派生竞态、断线期输出补齐
- **P3**：死代码清扫、ResizeObserver 泄漏、CSV 公式注入、错误路径 textContent 化
