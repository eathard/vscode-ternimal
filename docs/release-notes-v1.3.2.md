# Ternimal v1.3.2 — 多电脑书签：中继钥匙串

## 问题

扫码打开的中继链接 `#S=<子码>&T=<令牌>` 会被立即抹除片段（审计 P0：令牌不得驻留地址栏/历史/截屏），导致**手机书签丢失后缀、无法免扫码回访**。而一台手机常需连接**多台电脑**——所有主机共用中继源（同源），单条全局凭据会互相覆盖、书签彼此无法区分。

## 方案：按子码分钥匙串（S/T 安全属性分离）

| 片段 | 角色 | 安全性 | 处置 |
|---|---|---|---|
| `#S=` 子码 | **主机标识** | 非机密（无令牌通不过挑战应答） | **保留在 URL**——地址栏可安全截屏，书签可携带、可区分多台电脑 |
| `#T=` 令牌 | 活凭据 | 机密 | auth-ok 后**按子码存 localStorage 钥匙串**（30 天滑动 TTL） |

### 体验流

```
扫码 #S&T ──► 连接成功 ──► 钥匙串记住此电脑，地址栏变 #S=x ──► 此刻收藏书签 ✓
书签 #S=x ──► 钥匙串命中 ──► 免扫码直连（30 天内，每次连接续期）
多台电脑 ──► 一机一码一书签一钥匙串条目，互不覆盖 ✓
```

- 手输卡/被拒卡附「已保存的电脑」列表（掩码子码 + 剩余天数 + 连接/忘记）
- 子码被吊销 → 钥匙串同步作废该行；TTL 过期自动清扫
- 令牌**仅在服务端接受后**落盘；隐私模式（localStorage 不可用）静默降级回旧行为
- 令牌永不进 URL/书签/历史（P0 原则不破）
