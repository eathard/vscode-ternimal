# Ternimal v1.3.3 — 书签即全链：完整 URL 常驻地址栏

## 问题

扫码打开的中继链接 `#S=<子码>&T=<令牌>` 曾被立即抹除片段（旧 P0 策略：令牌不驻留地址栏），导致手机**点收藏存下的是裸地址**，书签打不开会话。

## 方案（产品决策，2026-09-16）

**完整 URL 常驻地址栏，凭据零落盘。**

- 页面加载后**不改写 URL**——`#S=&T=` 全链始终在地址栏
- 用户点收藏 → 书签存完整 URL → 重开书签/刷新/新标签页直接连上，多台电脑各是各的链接、天然互不干扰
- **不写 sessionStorage、不写 localStorage、无任何钥匙串**——URL 是凭据的唯一载体，由用户自行收藏保管
- 手清地址或直达根路径 → 手输卡提示重新扫码

## 安全边界（已知悉并接受的取舍）

| 面 | 状态 |
|---|---|
| 令牌达服务器日志 | **不会**（`#` 片段不上行，始终如此） |
| 地址栏截屏 / 复制链接 / 浏览器历史 | **会含令牌**（本决策的代价；业主拍板接受） |
| 失效手段 | 子码随时可吊销（管理页/主机侧）；分享令牌可轮换 |
